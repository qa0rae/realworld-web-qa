# 초기 테스트 시나리오

상태: 설계 초안 / 모든 시나리오 Not Run. 아래는 상세 TC가 아니며 실제 입력·단계·환경과 명세 근거를 추가한 뒤 실행한다. P1/P2는 실행 순서이며 결함 심각도가 아니다.

공통 전제: 실행 환경과 API 주소를 기록하고 본인 테스트 데이터만 사용한다. 관계/타인 권한 테스트는 A/B 계정 공유가 가능해야 한다. 불가능하면 Blocked다. HTTP 코드와 입력 한계는 실행 명세에 따라 확정한다.

| ID | 기능 | 우선 | 조건 및 동작 | 검증 기준 / 기대 결과 |
| --- | --- | --- | --- | --- |
| S01 | F01 | P1 | 새 계정으로 유효한 필수값을 입력해 가입 | 응답 계정과 UI 사용자 일치, 후속 인증 조회 일치 |
| S02 | F01 | P1 | 필수 필드별 누락, 중복 계정 입력 | 명세에 맞는 오류, 의도하지 않은 계정 생성 없음 |
| S03 | F02 | P1 | 유효 계정 로그인 후 새로고침 | UI와 현재 사용자 조회 일치; 유지 정책은 사전 확정 |
| S04 | F02 | P1 | 잘못된 비밀번호/필수 누락 로그인 | 오류 안내, 인증 상태로 전환되지 않음 |
| S05 | F02 | P1 | 로그아웃 뒤 보호 기능 진입; API 토큰 누락/변조 | UI는 비로그인 상태, 보호 API는 비정상 인증 요청 거부 |
| S06 | F03 | P2 | 본인 프로필 수정 후 재조회/새로고침 | 수정값 일치, 작성자 표시의 관련 영향 대조 |
| S07 | F04 | P1 | 글 생성→상세/목록 조회→본문 수정 | 응답과 조회/UI가 일치, 변경하지 않은 필드 보존 |
| S08 | F04 | P1 | 제목 변경 뒤 식별자와 연관 화면 재조회 | 명세에 따른 식별자 변경, 새 식별자로 접근 가능 |
| S09 | F04 | P1 | 본인 글 삭제 후 목록·상세 재접근 | 삭제 결과가 후속 조회에 반영, 오래된 상세에서 성공 표시 없음 |
| S10 | F04/F05 | P1 | 비로그인 및 B 계정으로 A 글/댓글 수정·삭제 요청 | 권한 정책 대조; 비인가 변경이 없어야 함. 코드 확정 필요 |
| S11 | F04 | P1 | 생성 필수 누락 및 확정된 입력 길이 경계 | 유효/무효 구간이 정책과 일치, 실패 시 잘못된 생성 없음 |
| S12 | F05 | P1 | 본인 글에 댓글 작성→재조회→삭제 | 내용/작성자/대상 글 연결 일치, 삭제 후 미노출 |
| S13 | F05 | P2 | 댓글 필수 누락, 삭제된 글에 작성 시도 | 명세에 맞는 오류 및 화면 복구; 성공으로 오인하지 않음 |
| S14 | F06 | P2 | B를 팔로우→피드 조회→해제→재조회 | 관계 상태와 피드가 정책에 맞게 변경; 계정 공유 전제 |
| S15 | F07 | P2 | 즐겨찾기→목록/상세 재조회→해제 | 선택 상태·개수·사용자 목록 일치, 해제 후 원상 반영 |
| S16 | F06/F07 | P2 | 연속 클릭/반복 요청 및 응답 지연 | 최종 UI와 조회 상태 일치; 반복 처리 정책은 확정 필요 |
| S17 | F08 | P2 | 태그 선택 후 목록 조회, 결과 없는 필터 조회 | 조건에 부합하는 글만 표시, 빈 상태 안내 |
| S18 | F09 | P2 | 데이터 0/1/n-1/n/n+1건에서 처음·마지막 이동 | 고정 데이터에서 누락/중복 없이 이동, 개수와 페이지 계산 일치 |
| S19 | F08/F09 | P2 | 뒤 페이지에서 필터/피드 전환 | 페이지 위치 처리 정책에 맞는 요청과 결과; 정책 확인 필요 |
| S20 | F09 | P2 | limit/offset 0·음수·형식 오류·총건수 이상 | 실행 명세 기준 허용/거부 판정; 임의 상한을 가정하지 않음 |
| S21 | F04/F05 | P1 | 쓰기 요청 실패/응답 손실 후 조회 및 재시도 | 실패 시 성공 안내 없음, 실제 반영 여부 확인 후 중복 여부 관찰 |
| S22 | F02/F04/F05 | P1 | 로그인→글 생성/수정→댓글 작성/삭제→글 삭제 | 핵심 여정 전체에서 UI/API와 후속 조회 일치 |

## 상태전이 포인트

| 객체 | 전이 | 실패/금지 전이 후보 |
| --- | --- | --- |
| 인증 | 비로그인→로그인→로그아웃 | 로그인 실패→인증 상태, 로그아웃 후 보호 요청 |
| 글 | 미생성→생성→수정→삭제 | 실패 응답인데 성공 표시, 삭제된 글 수정 |
| 관계 | 미선택→선택→해제 | 요청 실패인데 선택 유지, 계정 전환 후 이전 사용자 상태 잔존 |

## 상세 TC 작성 필드

TC ID / 연결 시나리오·기능 ID / 명세 근거 / 우선순위 / 환경 / 사전조건 / 정확한 입력값 / 번호 있는 단계 / 단계별 기대 결과 / 정리 절차 / 실제 결과 / 실행 상태 / 증거 / 결함 ID.

실행 후 상태를 갱신하고 재현 불가·환경 제한과 제품 결함을 구분한다. 수치 제한, 자기 팔로우, 빈 문자열과 공백의 처리처럼 명세가 미확정인 항목은 탐색 결과와 정책 확인을 먼저 기록한다.
